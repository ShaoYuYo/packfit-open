# PackFit Open 使用指南（繁體中文）

這是一個免費、免註冊的電池估算網站。除了可選的瀏覽器電池狀態功能，所有容量與設計規格都由使用者提供或匯入，網站不能直接掃描 Windows 電池韌體。

網站：https://shaoyuyo.github.io/packfit-open/

## 從哪裡開始？

1. **總覽**：輸入電池容量（Wh）和平均耗電（W），估算續航時間。
2. **今天的電量夠用嗎？**：輸入目前電量、預留電量及預計活動的使用時數和耗電，看看能不能完成今天的計畫。
3. **我的電池**：按「偵測我的電池」，若瀏覽器支援，顯示電量與充電狀態。要看容量保留率請用 Windows 報告或手動輸入。
4. **生活工具**：估算充電電費、行動電源可用能量以及充電時間。
5. **電池設計室**：提供串並聯與能量密度估算。
6. **設計比較**：儲存四組參數、匯出 CSV 或 JSON、匯入 JSON 還原。

## Windows 電池健康度怎麼看？

1. 按 Win + R，輸入 cmd，然後 Enter。
2. 貼上這行指令：

    powercfg /batteryreport /output "%USERPROFILE%\Desktop\battery-report.html"

3. 在桌面尋找 battery-report.html，回網站「我的電池」，點「匯入 Windows 電池報告」選取檔案。
4. 部分 Windows 會將桌面重新導向 OneDrive。請以命令顯示的輸出路徑為準。
5. 如果報告格式無法解析，找到 DESIGN CAPACITY 和 FULL CHARGE CAPACITY，換成 Wh 手動輸入即可。

容量保留率 = 滿充容量 ÷ 設計容量 × 100%。這不是對安全、故障或整體電池性能的完整診斷。循環次數如果報告沒有提供，便顯示「未提供」。

**隱私**：HTML 只在瀏覽器本機解析，不傳送到伺服器，不保存序號。請勿在 GitHub 公開上傳包含個人或裝置識別資料的完整報告。

## 今日電力規劃的簡單例子

56 Wh 電池、目前 80%、想預留 10%；預計文書 2 小時 × 10 W，影音 1 小時 × 14 W：

- 預計耗能：34 Wh。
- 保留底線後可用：56 × (80% − 10%) = 39.2 Wh。
- 活動結束後預估電量：(44.8 − 34) ÷ 56 = 約 19.3%。

10 W 與 14 W 都只是示範，並非任何型號的官方功耗。

## 如何備份或換電腦？

在「設計比較」點「備份 JSON」，即可下載 packfit-scenarios.json。在新裝置選「匯入 JSON」。匯入將取代該瀏覽器已有的方案，系統會先要求確認。也能先下載[公開的合成範例](../examples/sample-scenarios.json)試用；資料並非實際產品規格。

CSV 可以用 Excel 看數據；JSON 才能回到 PackFit 編輯。

## 能離線使用嗎？

支援 Service Worker 的 HTTPS 瀏覽器，第一次連線載入後會快取計算程式。之後斷網時通常可以繼續使用，但快取與安裝到主畫面的支援度依瀏覽器而定。Google Fonts 離線時由系統字型代替。清除網站資料可能刪除快取和本機儲存的方案。

## 重要限制

這不是電池充電控制、BMS、安全、機構可行性或航空運輸認證工具。不要以估算值直接設計、製造或改造電池包。詳見[完整方法](METHODOLOGY.md)。
