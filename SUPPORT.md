# Support

PackFit Open is a volunteer open-source project.

## Get help

- Read the [Traditional Chinese guide](docs/USER_GUIDE.zh-TW.md) or [English guide](docs/USER_GUIDE.en.md).
- For calculations, review [methodology and assumptions](docs/METHODOLOGY.md).
- For reproducible errors or proposals, [open an Issue](https://github.com/ShaoYuYo/packfit-open/issues/new/choose).
- For vulnerabilities or confidential information, read [SECURITY.md](SECURITY.md); do not disclose exploit instructions publicly.

## Report useful details

Please include the steps, browser and OS, actual versus expected behavior, and only **synthetic or public data**.

Do not post system serial numbers, identifiable Windows reports, employer data or confidential supplier specifications.

## Scope

Maintainers can investigate math discrepancies, report parsing errors, localization, usability, accessibility and import/export bugs. This project does not provide battery fabrication or electrical safety certification.

Some browsers do not implement the Battery Status API; a missing live status is not necessarily a website bug.
