# Community Code of Conduct

PackFit Open welcomes contributions from people with different backgrounds, including beginners, students, repair enthusiasts and professional engineers.

We expect respectful, constructive discussion. In particular:

- Critique calculations, designs and ideas rather than people.
- Give credit for others' work and avoid misleading claims.
- Do not harass, threaten, discriminate against, or publish personal information about other people.
- Respect confidential employer, customer and supplier information.
- Refrain from unsafe hardware advice presented as certified engineering.

Maintainers may edit or remove abusive content and close discussions that violate these expectations. To report serious concerns, contact repository maintainers through an appropriate private GitHub channel rather than publicizing identifying or security-sensitive details.

This community code is project-specific and applies to issues, pull requests and project discussions.
